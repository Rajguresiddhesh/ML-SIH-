# On-device model assets

Generated by the scripts in `../../../tools/`:

| File | Producer | Used by |
|---|---|---|
| `symbol_detector.tflite` | `python tools/export_yolo_tflite.py` | packaging-symbol detection (FSSAI / Veg / ISI / recycling / bar code) |
| `compliance_ebm.json` | `python tools/export_ebm_to_json.py` | *optional* EBM second opinion — the default verdict is the deterministic rulebook |

Both are optional. The app runs a full Rule 6 audit from the bar code / OCR
without either file. Drop the generated files here and rebuild.
